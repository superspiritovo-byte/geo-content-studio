# Chrome 扩展连接实施计划

> 执行：本次在当前功能分支实现；保留之前尚未提交的 RAG 与人工确认改动，不纳入不相关重构。

目标：登录和发布准备复用用户现有 Chrome 的标签页，不再启动独立浏览器。扩展手动加载一次，配对本机工作台。

架构：MV3 扩展轮询经过随机配对凭据保护的本机任务队列。仅接受六个平台的固定操作（打开、当前身份、准备正文和图片），不接受任意脚本。平台登录凭据不导出。服务端沿用身份比较、不可变快照和防重状态；扩展模式最终提交由用户在平台检查确认，系统不擅自点击发布。公开自动核验继续使用匿名后台检查。

约束：默认扩展模式；断线不回退到独立 Chrome。现有账号不迁移登录文件，当前普通 Chrome 账号必须匹配已保存身份。复用标签页时发布准备先单独建立标签，避免覆盖用户正在编辑的页面；同一待处理任务不重复准备。扩展安装无法静默替用户完成。

- [x] 本机配对、凭据与持久任务队列：随机一次性配对码、凭据散列、绑定扩展 Origin，单消费者领取、超时禁止重播、断线可见。新增测试先失败再实现。
- [x] MV3 扩展：弹窗配对/断开，固定平台 URL，身份接口仅返回必要公开字段；读取/填入必须检查平台域名；同平台唯一可确认身份；图片保留顺序，正文回读失败暂停，最终人工提交。
- [x] 发布助手接入：默认扩展，原独立模式显式保留；登录/读取/发布通过桥接，身份不符暂停；图文/文章均暂停待用户处理，无新增自动提交。
- [x] 页面连接状态、安装说明和文件夹入口；测试断线、错误来源、重复回执、账号不符、已有草稿不覆盖。
- [x] npm test、类型检查、生产构建、隔离扩展浏览器验证；更新正在运行的本机服务。用户真实 Chrome 最后加载扩展并配对后才能验收真实平台。

依据：Chrome 官方 scripting executeScript 和 service worker 生命周期文档。权限仅 tabs、scripting、storage、alarms 及本机/六个平台域名；不请求 debugger、cookies 或全部网站权限。

## 审查与验证记录

- 独立审查发现 3 项 Important：长操作缺独立心跳、同源 iframe 正文缺回退、仅图片草稿未保护。均纳入一次修复验证；无 Critical 或额外 Minor。
- 心跳独立每 15 秒执行，不领取新任务；API 测试验证 queued 任务不因心跳被领取。
- 虚拟 HTTPS 页面实际加载 MV3 扩展验证配对、复用标签/窗口、身份、富文本、已有文字/图片草稿保护、同源 iframe。测试不等于真实平台适配验收。
- 所有操作固定平台与用途，不提供远程任意脚本或 cookies API，不静默启动另一个浏览器。

用户验收待办：日常 Chrome 加载扩展、粘贴配对码后，检查真实连接与各平台的现有登录；没有执行真实平台发布。
