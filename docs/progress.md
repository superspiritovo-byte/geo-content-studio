# GEO 第一版实施记录

依据：本次聊天中用户确认的《GEO 精准获客平台第一版方案》。

- 初始目录为空，无 Git 仓库、现存代码或需要保护的分支，直接在用户指定目录创建项目。
- 实施顺序：存储与业务约束测试 → 服务端和 AI → 发布助手 → 页面 → 集成和浏览器验证。
- 视觉：白色侧栏 230px；背景 #f8fafc；文字 #101828；蓝色 #245bea；浅蓝 #eef4ff；边框 #e4e8ef。中文使用 Microsoft YaHei / PingFang SC，无外部字体依赖。
- 决策：Node 24 原生 SQLite，避免 Windows 原生依赖编译；AI 使用可配置的 Chat Completions 兼容协议。
- 决策：未取得真实账号前，不宣称三平台适配已验证；保守识别身份及提交结果，无法证明则转人工处理。
- 决策：首版封面限 PNG/JPEG/WebP；不支持正文图片。

## 2026-11-02 知乎已登录但身份读取失败

- 根因：初版只查导航/头像的带姓名作者链接，遗漏头像无文字、姓名在个人主页标题区的页面；助手固定使用第一个标签页，也可能错过新打开的平台页。
- 修复：优先读取同一独立浏览器会话的知乎当前账号接口；受限时仅接受同时具有“编辑个人资料”的本人主页与唯一姓名。拒绝将他人主页标题作为登录身份。
- 修复：优先选择该平台最新的未关闭标签页；重启后空白页自动打开平台入口；避免在没有图片的链接上等待图片属性超时。
- 回归：新增 4 项身份识别测试，总计 21 项测试通过；生产构建及 TypeScript 检查通过。
- 真实验证：重启后保留原账号独立浏览器会话，读取身份操作成功，页面显示账号“测试账号”和“待你确认”。未替用户点击确认保存，未触发任何文章发布。

## 百家号及搜狐号身份适配

- 百家号：读取已登录账号设置中的姓名与数字ID，真实会话已成功识别 测试账号。使用独立后台身份标识，不假定数字ID就是公开作者 app_id，因此公开署名核验仍保守处理。
- 搜狐：从官方当前前端公开资源确认 /mpbp/bp/account/listV2 接口、组织分组 accountInfos、nickName/id/status 字段及浏览器内认证请求头；不再仅依赖作者超链接。认证请求在浏览器内执行，凭证不导出、不记录。
