# GEO 精准获客平台

面向 GEO 内容运营的 AI 工作台，支持企业知识库、智能选题、文章生成、富文本编辑及六大平台辅助发布。基于 Next.js、TypeScript、SQLite 和 Playwright 构建。

## 启动

需要 **Windows、Node.js 24+、Google Chrome**。双击 `start.cmd`，或在 PowerShell 的项目目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
```

脚本会检查依赖、构建应用并启动网页与助手。打开 **http://127.0.0.1:18080**，关闭服务按启动窗口中的 Ctrl+C。默认仅绑定本机地址。不要将该内部单用户版本通过反向代理公开。

开发与检查：

```powershell
npm ci
npm run dev
# 另一个终端中启动助手
npm run worker
npm test
npm run typecheck
npm run build
```

`npm run dev` 默认使用 3000 端口；一键启动使用 18080。通过 `PORT` 可调整启动脚本端口。

## 首次使用

1. 设置：输入 AI 服务商的 Chat Completions 兼容基础地址（通常以 `/v1` 结尾）、模型 ID、密钥和上下文容量，保存后测试连接。系统不会提供或购买密钥。测试会调用真实模型并可能产生服务商费用。
2. 企业资料：上传 UTF-8 TXT/Markdown 或 DOCX，或粘贴文字。最多 10 文件，每个 8MB。失败文件不会用于生成。PDF 需先转换格式。
3. 工作台：选择资料、读者和写作目的，生成选题；也可以直接写文章。所有选题与正文调用真实模型，无模拟生成。
4. 我的文章：修改并保存，预览并核对事实、价格、案例和联系方式。支持复制与 Markdown 导出；首版正文不支持图片。
5. 发布账号：添加知乎、百家号或搜狐号账号，打开平台窗口并自行登录，点击“读取身份”，核对后确认保存。验证码及密码不经过工作台。
6. 发布确认：选择账号、封面并勾选确认。百家号默认要求封面。提交后按账号记录结果。
7. 发布结果：可粘贴该账号公开文章链接，点击检查结果。只检查公开内容，不会再次发布。

## 发布能力与边界

实现了三个平台的独立适配器和真实浏览器交互，但**未用真实账号验证三个平台的完整发布流程**。平台页面和风控随时可能改变，身份控件或编辑器无法唯一识别时会暂停，需要人工处理。系统不会跳过验证码，不会把点击按钮当成发布成功。

- 发布助手和公开结果检查均使用 Google Chrome，每个账号的独立目录为 `profiles/chrome/<账号ID>`，不访问日常 Chrome 资料。旧 Edge 目录保留，不直接混用不同浏览器的登录数据；切换后需要在专属 Chrome 窗口重新登录。账号姓名与稳定标识读取后由用户确认。
- 自动操作包括保守识别、文章填入和单次发布按钮点击。遇到后续确认弹窗、AI 声明、封面裁剪或审核，用户需在平台窗口继续处理。
- 正文在发布编辑器中转换为 HTML；不包含内联图片。封面上传位置不唯一时不会猜测。
- 核验使用不携带账号 Cookie 的新浏览器上下文，检查公开文章 URL、作者链接、标题和完整正文。若平台未暴露足够信息，即使文章可能已经发布，也保留待核验，不能据此重发。
- 一次提交保存不可变文章快照。相同文章版本、封面和账号不能重复排队；已尝试提交的任务不能自动重试。
- 中断任务转为人工处理；只有尚未尝试点击发布的任务可手动“重新准备”。重新准备前用户需确认没有手工发布。
- 网页关闭后，助手仍可能继续已确认的排队任务；停止整套服务请在启动窗口按 Ctrl+C。

## 数据和安全

默认数据位置为 `%LOCALAPPDATA%\GEOStudio\data`，与 OneDrive 项目目录分开。可用 `GEO_DATA_DIR` 环境变量指定独立目录，网页和助手必须使用相同目录。

- `geo.sqlite`：资料文字、文章、账号元信息、选题、发布记录、设置。
- `documents/`：上传原文件；`covers/`：封面；`profiles/`：发布账号登录会话；`logs/`：运行日志。
- AI 密钥通过 Windows 当前用户的 DPAPI 保护，只保存密文，不通过接口回显。新浏览器会话由 Chrome 管理，仍应保护当前 Windows 用户与数据目录。
- 生成时会将所选企业资料发送给配置的服务商。上下文按 UTF-8 字节保守估算并预留提示词/输出空间，超限拒绝而非截断。
- 删除资料会删除关联上传文件，保留已生成文章和发布快照。移除账号会保留浏览器会话目录，确认不用后可关闭助手并手动删除该账号目录。
- 备份前停止网页和助手，再复制整个数据目录；DPAPI 密钥只能由原 Windows 用户解密，换电脑后需要重新输入 AI 密钥并重新登录平台。

## 验证范围

测试覆盖资料隔离、容量拒绝、模型 JSON 解析、持久化、发布快照、防重复提交、账号及封面校验、中断恢复、公开链接限制、作者标识与全文匹配。真实 AI 与真实公开发布的最终验收，需要用户配置模型及账号，在工作台明确确认后完成。

Node.js 原生 SQLite 在当前 Node 24 中仍会打印 ExperimentalWarning，这不表示数据库操作失败。

## 新增图文平台（辅助发布，待真实账号验证）

新增小红书图文笔记、抖音图文作品、哔哩哔哩图文动态，不包含视频或 B站旧版专栏。

- 发布账号中可选择三个新平台，使用同样的独立 Chrome 会话。账号身份无法唯一核对时会暂停，不使用手工编造的昵称冒充登录成功。
- 发布确认页选择图文账号后显示专用标题、正文、图片表单。正文初始由文章转成可编辑的纯文案，不修改原文章。
- 首版最多9张 PNG/JPEG/WebP，每张不超过8MB，支持预览、移除和前移调整。首版保守文案限制：小红书标题20字/正文1000字，抖音30/1000，B站100/2000；超限要求修改，不截断。
- 图片复用本机 covers 文件存储，但图文任务独立保存有序图片列表和专用文案快照，修改后不影响历史任务。
- 助手尝试真实上传图片并填入文案，然后暂停。用户在平台窗口核对图片顺序、话题、声明并最终发布。表单变化、登录验证、上传控件不唯一会明确转人工处理。
- 新平台尚未经过真实账号端到端验证，图片上传成功、最终提交成功、公开图文核验均不能据构建或单元测试推定。新平台不会自动显示“已公开发布”。提供完整图文链接可保存为人工核对记录，系统不会重复提交。
- 不提供自动配图、自动生成视频、平台专用 AI 改写；首版文案在发布确认页直接编辑。
